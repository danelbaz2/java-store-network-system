> הסבר קצר על הפעלת המערכת:

## 1. הפעלת השרת:

מריצים את הסקריפט run_server.bat

## 2. הפעלת הלקוח:

מריצים את הסקריפט run_client.bat
מזינים נתונים לפי מה שמוצג.
ניתן להעזר בקובץ config.json על מנת להזין את הנתונים הרלוונאטיים.
